## 🚖 About TriFare

TriFare is a BSIT Capstone Project developed to modernize tricycle fare computation in Kidapawan City through GPS-assisted fare metering.

The system includes:

* Driver Application
* Admin Dashboard
* Applicant Registration Module
* Analytics and Reporting
* Automatic Fare Computation
* Passenger Discounts
* Trip Recovery
* Custom Ride Support
