Security

Trips and data, protected.

TriFare separates access by role and keeps trip records auditable.

  • Role-based access

    Drivers, admins, and applicants each see only their own interface and data.

  • Encrypted authentication

    Sign-in is handled through Supabase Auth with hashed credentials.

  • Document verification

    Applicant documents are reviewed and approved by admins before activation.

  • Trip integrity checks

    GPS jump filtering (max 80 m) and accuracy thresholds prevent fare tampering via spoofed locations.

FAQ

Frequently asked questions.

Does TriFare work without internet?

Yes, trip tracking and fare computation work offline. Trips are recovered automatically if the app closes or the connection drops, and sync to the server once a connection is available.

How is the fare calculated?

TriFare uses a base fare for the first 3.75 km, plus ₱0.40 per additional 100 meters (₱4.00/km). Discounted passenger types (Student, Senior, PWD, Child) are applied automatically.

Can drivers set a custom fare?

Yes. Custom / Exclusive Ride lets a driver agree on a fixed fare with a passenger while still recording distance, duration, and trip history for reporting.

How do I become a driver on TriFare?

Register an applicant account, fill out the driver application, upload required documents, and track your review status from the app. Admins approve applications before driver access is granted.

Is TriFare available on iOS?

Not currently. TriFare is distributed as an Android APK via GitHub Releases during this pilot/capstone phase.
